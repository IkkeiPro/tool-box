# Excel Masker

Excel内の個人名を「A社のメンバー1」などの共通ラベルに置き換える、ローカル実行のアプリです。HTMLの入力画面とPython標準ライブラリだけで動作します。

## 起動

リポジトリをダウンロードまたはクローンし、Python 3.10以降が利用できる環境で実行します。

```sh
python app.py
```

macOS / Linuxでは環境によって `python3 app.py` を使ってください。起動後にブラウザが開かない場合は、コンソールに表示されたURLを開いてください。

`start.bat` をダブルクリックするとブラウザが開きます。Python 3.10以降で動作し、追加パッケージは不要です。このPCではCodex同梱Pythonを使います。他のPCではPythonをインストールし、`python app.py` でも起動できます。

1. 対応表に個人名と会社ラベル（A社・B社など）を入力します。
2. 「会社別に連番を割り当て」でA社のメンバー1などを設定します。直接編集もできます。連番ボタンは既存の置換後の名前を上書きします。継続分析では保存した対応表を再利用してください。
3. 複数の.xlsxファイル、またはフォルダを選びます。フォルダ内のサブフォルダも含みます。
4. 「マスキングして生成」を押し、結果のZIPを保存します。元ファイルは変更しません。

## 置換の仕様

- 全シート（非表示を含む）の文字列を対象に、長い登録名を優先して部分一致・一度だけ置換します。全角半角やスペースの違いは別の登録が必要です。
- 同じ名前を複数の会社に割り当てることはできません。同姓の人はフルネームなどに揃えてください。複数表記を同じ別名へ割り当てることはできます。
- 数値・書式・数式参照は維持します。数式内の引用文字列は置換します。Excelによる数式再計算は行いません。
- セルのリッチテキストにまたがる名前も置換します。その文字列全体には先頭の文字書式が適用されます。
- コメント、図形内テキスト、文書プロパティ等のXML文字列も処理します。
- シート名・数式参照・XML属性に登録名が残る場合、そのファイルは出力せず理由を表示します。Excelで対象箇所を変更して再実行してください。
- 画像内の氏名は検査・置換できません。画像を含む場合は結果画面に表示します。埋め込みファイル、マクロ、電子署名付きブックは拒否します。.xls/.xlsm/暗号化ファイルは未対応です。
- 出力名はmasked_001.xlsx等です。入力ファイル名やフォルダ名の実名を持ち出さないためです。元ファイルとの対応は結果画面で確認できます。
- 件数はXML文字列の置換回数です。Excelの共有文字列は複数セルで参照されるため、セル数・人数とは一致しません。
- 対応表にない名前や、画像内などの名前について匿名化を保証するものではありません。AIへ渡す前に内容を確認してください。

## データの扱い

ブラウザからこのPC内のPython（127.0.0.1）へ送ってメモリ上で処理します。外部API、CDN、アクセス解析は使いません。入力をサーバーのディスクに保存しません。対応表を保存したJSONは実名を含むため、分析用ZIPとは別に保管してください。ブラウザの更新で対応表は消えます。

100ファイル、合計100MB、1ブックの展開後300MBが上限です。処理中は対応表やファイル選択を変更せずにお待ちください。終了時は起動したコンソールを閉じてください。

## 開発・テスト

```sh
python -m unittest -v test_app
```

GitHub Actionsでもテストを実行します。実データのExcel、対応表JSON、生成ZIPは `.gitignore` で除外しています。対応表を共有する場合は架空のサンプルに置き換えてください。
